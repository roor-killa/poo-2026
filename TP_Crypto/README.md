Étapes - Transfert Local

Ouvrir un terminal dans le dossier du projet
Lancer la commande : python local_transfer.py
Suivre le menu affiché


Étapes - Transfert Réseau

Ouvrir VS Code dans le dossier du projet
Ouvrir un premier terminal : Terminal → New Terminal
Lancer le serveur : python network_server.py
Entrer le nom du propriétaire et le solde initial
Appuyer sur Entrée pour le host et le port
Ouvrir un deuxième terminal : Terminal → New Terminal
Lancer le client : python network_client.py
Entrer le nom et le solde initial
Choisir une option dans le menu
